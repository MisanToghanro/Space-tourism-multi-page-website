# Frontend Mentor - Space Tourism Website Solution

This is my solution to the Space Tourism Website challenge on Frontend Mentor. The project focuses on building a responsive multi-page experience while dynamically rendering content from a local JSON file using JavaScript.

## Overview

### The Challenge

Users should be able to:

* View each page and toggle between tabs to see different information.
* View the optimal layout depending on their device's screen size.
* See hover states for all interactive elements.
* Navigate through the Home, Destination, Crew, and Technology sections.
* View dynamically rendered content from a local `data.json` file.
